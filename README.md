# fe-next-css-starter

Next.js (App Router) + TypeScript, styled with plain **CSS Modules**.

## Stack
- Next.js 15 (App Router)
- React 19
- TypeScript
- CSS Modules (`*.module.css`) + a global `app/globals.css`

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Build
```bash
npm run build
```
